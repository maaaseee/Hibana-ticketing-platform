## Brand & Style

This design system channels an immersive, high-tech event ticketing experience set against oceanic depth. The emotional posture balances precision engineering with vibrant nightlife energy: confident, nocturnal, focused, and frictionless. 

Drawing from modern high-contrast digital craftsmanship and refined dark-mode utility, the aesthetic relies on cavernous slate depths paired with electric bioluminescent accents. Contrast is structural rather than ornamental—content fields emerge naturally through tonal shifts, while key actions spark with concentrated cyan and teal brilliance. The system avoids visual clutter, favoring razor-sharp typographic hierarchy, high-density metadata displays, and clear transaction paths.

## Colors

The palette simulates abyssal strata, grounding user focus in deep midnight tones while projecting interactive elements via sharp chromatic shifts.

### Surface Architecture
- **Canvas Base (`#0b131e`)**: Deep abyss canvas for edge-to-edge application chrome and overall backdrop.
- **Surface Dim (`#0e1927`)**: Recessed modules, table headers, and backdrop panels.
- **Surface Default (`#132235`)**: Primary section blocks, modals, and container shells.
- **Surface Elevated (`#172a42`)**: Distinct cards, floating toolbars, and elevated trays.
- **Surface Interactive (`#1a2d47`)**: Resting state for selectable cards, input fields, and hover fills.

### Accents & Signatures
- **Primary Anchor (`#00688f`)**: Structural branding, secondary button fills, selected tab indicators, and authoritative accents.
- **Active Bioluminescence (`#14b8a6`)**: Success prompts, confirmed ticket statuses, and active stage triggers.
- **Electric Cyan (`#38bdf8`)**: Primary conversion triggers, time-sensitive badges, seat-selection states, and critical CTAs.

### Typography & Ink
- **High Emphasis (`#f0f4f8`)**: Primary headlines, ticket titles, seat numbers, and pricing callouts.
- **Medium Emphasis (`#cbd5e1`)**: Body copy, descriptions, structural labels, and metadata values.
- **Muted (`#64748b`)**: Inactive states, placeholder values, and timestamp indicators.
- **Borders & Dividers (`#1e3a5f`)**: Hairline outlines to maintain surface separation without breaking dark immersion.

## Typography

The typographic engine uses a tripartite structural approach:
- **Headlines (`Space Grotesk`)**: Technical, modern, and sharp geometry for artist billings, venue names, and section titles.
- **Body (`Hanken Grotesk`)**: Highly legible, contemporary grotesque neutral sans for transactional flows, policies, and venue guidance.
- **Labels & Metas (`JetBrains Mono`)**: Strict, monospaced alignment for dates, tiers, seating allocations, barcode references, and currency amounts.

Display scales step down on mobile breakpoints to preserve viewport space and avoid awkward hyphenation in event titles.

## Layout & Spacing

The layout is built on a responsive 12-column fluid grid on desktop (max width 1440px), translating to an 8-column layout on tablet (768px - 1024px), and a 4-column layout on mobile (<768px). 

Vertical rhythms follow strict 8px increments. Dense ticket checkout flows rely on `space-sm` and `space-md` internally to keep critical transaction parameters above the fold. Outer card containers and stage-selection maps scale margins dynamically with `margin-mobile` collapsing to edge rails for maximal touch area.

## Elevation & Depth

Visual hierarchy does not use diffuse, warm drop shadows. Instead, it leverages atmospheric marine luminance, surface luminance tiers, and precision borders:

- **Tonal Stratification**: Elevation rises by stepping colors upward (`#0b131e` base → `#0e1927` dim → `#132235` card → `#172a42` floating).
- **Hairline Luminance**: Elevated components utilize a 1px top-lit inner or outer border (`rgba(56, 189, 248, 0.15)`) to delineate edges against pure dark backdrops.
- **Bioluminescent Radiance**: Focused, high-priority interactive components (active tickets, seat selections, primary modals) emit a subtle cyan ambient bloom (`box-shadow: 0 0 24px -4px rgba(56, 189, 248, 0.2)`).

## Shapes

The design system maintains a controlled, engineered shape aesthetic with a base `roundedness` level of `1` (0.25rem / 4px). Small UI elements (badges, code blocks, controls) use 4px corners; cards, seat modules, and modals use 8px (`rounded-lg`); while floating bottom sheets utilize 12px (`rounded-xl`).

Pill radiuses are restricted exclusively to standalone status badges (e.g., "SOLD OUT", "DOORS OPEN") and live telemetry tags to create direct geometric contrast against structural ticket frames.

## Components

### Buttons
- **Primary**: Solid `#38bdf8` background, `#0b131e` bold text. Subtle hover glow (`rgba(56, 189, 248, 0.35)`). Active state applies a 0.98 scale compression.
- **Secondary**: Outlined with `#1e3a5f` border, filled with `#132235`, high-emphasis text (`#f0f4f8`). Hover triggers border shift to `#14b8a6` and accent text tinting.
- **Ghost/Tertiary**: No border, background transparent, muted text (`#cbd5e1`), hover background `#172a42`.

### Cards & Ticket Modules
- Built on `#16263d` or `#1a2d47`. Divided by a dashed 1px SVG separator line (`#1e3a5f`) simulating a physical ticket tear notch. 
- Left section houses event graphics and metadata; right section isolates barcode, countdown timers, and monospaced seat designations.

### Chips & Badges
- **Status Chips**: Filled with translucent tints (`rgba(20, 184, 166, 0.12)`), bounded by 1px solid borders (`rgba(20, 184, 166, 0.3)`), with text set in `JetBrains Mono` at `label-sm`.

### Form Fields & Search
- Inputs use `#0e1927` fill with a resting 1px `#1e3a5f` border.
- Focus state expands border color to `#38bdf8` with an inline box-shadow of `0 0 0 1px #38bdf8`. Label text utilizes `label-md`.

### Selection Controls (Checkboxes, Radios, Toggles)
- Unchecked states sit in `#0e1927` with `#1e3a5f` border.
- Checked states snap instantly to `#14b8a6` with `#0b131e` iconography.

### Seat Selection Grid (Domain Specific)
- **Available Seat**: Circular 12px node in `#172a42`, outline `#1e3a5f`.
- **Selected Seat**: `#38bdf8` fill with a localized 6px cyan ambient halo.
- **Reserved/Unavailable**: `#0e1927` fill, no outline, 40% opacity.
